# Engineering decisions

## 2026-10-20

- Preserve the existing fork/history and work only on `codex/glm53-3pc-rpc`; use project-local nonpersonal Git attribution. Master is not an integration target yet.
- Pin upstream `1242be66f65d5d8a3d996ba56d6de106ced98cf6`, Unsloth revision `a38483c8cd5df544f53d70fb281afe97369d5ab6`, and official config revision `46a050bec13002ad29ee795c16e61cf4fa3c4a9c`.
- Reuse the already-merged GLM5Next/MTP/SLRU implementations. No open prototype PR is blindly merged. No expert top-k clipping, cache-biased routing or lossy wire precision is accepted.
- Inventory the exact quant before selecting an executor/placement. The five-layer laptop split has a 14.46 GiB all-target-weights/state lower bound; actual residency remains an engineering requirement.
- Keep KDA state FP32, matching upstream memory creation. FP16/BF16 sparse storage and FP32 transport are distinct precision decisions.
- Separate metadata planning from inference admission. The native planner explicitly reports NOT_VALIDATED for admission and does not claim missing runtime capabilities work.
- Use normal Windows-2022 hosted Actions for native builds, pinned verified CUDA 12.8.1 components and pinned CCCL. No paid infrastructure or physical GPU is provisioned.
- StrataRPC is a read-only design reference, not a source transplant. Its Qwen/two-stage state is not GLM's. DeepSeekRPC main resolved to `25de683e5ef3a9299267b8e61bafb1d755941c84`; no dependency or source import was taken.

## 2026-10-21

- Expose stage context creation through the experimental side header; keep ordinary model/context behavior and stable parameter structs unchanged.
- Use one shared ownership predicate for weights and all three memory components. Preserve all mHC streams through A/B and make boundary widths explicit in batch/output APIs.
- Start with single-sequence, causal, append-only evaluation. Reject unsupported pooling, MTP/rollback, backend samplers and cross-layer shared index selections. Default to full model context, capped at the target's 1,048,576 positions, without a hidden smaller fallback.
- Permanently invalidate a stage context after preparation/compute failure; recovery recreates contexts against retained weights. Distributed coordination/reset/replay remains required before this can serve requests across processes.
- Keep the monolithic evaluator as the oracle. Use independent intermediate captures and final logits, mixed KDA/DSA ownership and incomplete-pool/chunk boundaries to qualify local execution before transport integration.
- Use system CNG on Windows and libcrypto for Linux CPU authentication fixtures; do not implement cryptographic primitives. Bind HMAC keys to fresh connection nonces, canonical identity, direction and channel. Keep control frames independent and small. HMAC integrity is not encryption, and connection sequence checks do not replace session/transaction deduplication.
- Enforce mutual proof with one-use fixed-size handshake components and system-generated nonces. The client cannot expose a binding before the final server proof; all authentication errors permanently invalidate the handshake. Keep socket/identity construction and distributed admission as explicit remaining integration work.
- Use explicit unicast IPv4 interfaces, nonblocking sockets and absolute I/O deadlines. Shut down and permanently stop a failed stream instead of resuming partial frames. Keep socket handles valid during concurrent interruption and join users before destruction. Prove actual control/data independence over separate loopback sockets before connecting model processes.
- Qualify the compute chain with three actual owned-layer processes and a separate monolithic oracle. Keep fixture workers loopback-only with explicit small-model guards and per-run secret files, with no embedded worker credential. They remain separate from the production application until identity, admission and session transactions exist. Require missing-middle startup refusal and exact aggregate weight coverage.

- Validate complete descriptors through a guarded no-allocation native loader mode, rather than duplicating attention/KDA/NextN shape tables. Require real descriptors, including unknown-tensor count rejection; do not use the synthetic provider path as a schema validator. Keep payload verification and runtime admission false after metadata validation.

- Bind the complete execution contract with system SHA256 over explicit little-endian fields and length-prefixed ASCII identifiers. Hash bounded GGUF headers (including tokenizer/template metadata) and declared file sizes/revisions; do not require full-weight checksum passes. Treat this identity as a compatibility check, not payload integrity, binary attestation or resource admission.

- Receive a complete locally planned activation chunk before mutating model state. Authenticate every bounded fragment, require exact semantic coordinates and increasing fragment indices, cap the single input buffer by a local reservation, and permanently interrupt/discard on any error. Keep whole-chunk transport completion distinct from distributed model commit/reset.

- Start SSD work with read-only explicit-offset handles, no shared seek cursor or mmap, exact bounded byte transfers and source-mutation refusal. Keep the sealed memory expert store free of file handles/callbacks; a selected-expert miss fails. Do not equate a sealed heap catalog with Windows page locking or final laptop residency.

- Keep desktop raw-expert caching restricted to ranks 0/2 and the complete locally checked owned catalog. Deduplicate loads and evict only unleased LRU entries. Track payload reservations through final buffer deletion, including weak-lock races and data retained past cache ownership; do not free budget merely because a map entry was evicted. Fatal load failure stops new cache work. This does not change routing or create a laptop fallback.

- Qualify raw-cache-to-GGML bank materialization with real native quantized expert operators before changing model callbacks. Preserve original expert IDs for scales/biases and remap only GEMM slot IDs. Hold an exclusive compute lease through backend completion and poison any partly failed bank. Refuse excess distinct experts explicitly; do not clip router output or claim unimplemented wave execution.

- Integrate desktop sources through metadata-only routed tensors, owned native file offsets and per-context backend banks. Catch every provider exception inside the GGML callback and synchronize before decode checks its permanent failure status. Bound worst-case selected experts by an explicit microbatch instead of silently altering routing; keep context capacity independent. Require CPU-bank op_offload=false to prevent stale scheduler weight copies. Rank 1 continues to refuse this disk-backed API, and buffered heap remains insufficient for laptop admission.

- Preserve the original buffered three-process oracle. Qualify streamed A/C processes with a separate monolithic oracle at the same explicit microbatch 1, rather than relaxing exact boundary checks across different compute schedules. Require startup and final source counters without presenting native calls as physical SSD traffic or buffered B as resident.

- Retain immutable complete expert groups in backend banks. Reserve every selected hot slot before choosing unselected LRU victims, commit mappings only after all projection copies finish, and poison any failed replacement. Report backend reuse/copies separately from raw RAM-cache/native-file events; CPU bank counters are not GPU runtime evidence.

- Use dedicated OS allocations for locked host payloads instead of locking shared heap pages. Keep raw-byte and page-rounded lock budgets separate, verify actual native lock state and retain ownership through the final immutable lease. Fail lock/quota errors without a pageable fallback. A locked expert payload store does not establish complete laptop model/state/GPU admission.

- Give rank 1 a separate complete-catalog preload reader whose inference type owns no file/cache/callback capability. Reuse the checked metadata-only model tensors and leased graph banks without introducing a desktop fallback. Report expert locks and startup I/O while keeping full model/state/GPU admission false. Use a one-layer middle CPU fixture below the test lock quota and an explicitly scoped Windows test working-set adjustment; production code does not silently raise OS limits.

- Keep generic locked host-page ownership separate from per-expert I/O limits. Supply a standard GGML CPU-layout type with a shared reservation ledger and final-buffer release accounting. Contain all allocation exceptions at the C callback. Treat GGML zero-byte dummies as metadata borrowing their type owner. Qualify actual operators/scheduler and allocator concurrency before routing model/cache/workspace allocations through the pool; retain full-admission false until every relevant path and GPU resources are protected.


- Preserve v1 expert-only semantics and add explicit preload policy 2 with the same parameter layout. Make host_page_bytes one shared native-page budget covering raw experts and CPU tensor buffers. Reserve raw pages before startup reads; retain the memory-only owner and a lock verifier, never the loader. Refuse extra CPU packing/buffer overrides and propagate allocation failure without heap fallback. Keep GPU/default non-host types unchanged and full residency false until backend work buffers, metadata, network/staging and physical GPU resources are covered. Use separate small KDA/DSA CPU oracles under ordinary native lock quotas; do not weaken target model geometry or native verification.


- Route CPU backend direct and explicit-plan work buffers through an opt-in registry capability set once before use. Keep ordinary callers on their existing heap path and avoid changing stable public parameter layouts. Strict stage policy refuses a missing capability. Reserve replacement scratch before releasing old data, include both in peak capacity, and return allocation failure without fallback. Preserve real-model settings; only the separate small independent KDA/DSA CPU oracle uses one thread to fit test lock quota.


- Reuse the model's existing progress callback for startup expert preload and ordinary weights, with logical byte weighting and no regression to zero between phases. Derive ordinary bytes from actual tensor descriptors before loader mapping initialization. Keep callbacks local to startup, honor cancellation before/after complete expert reads and at ordinary-load completion, and unwind all partial pages/readers before returning no model. Retain the separate requirement for native in-flight I/O cancellation/deadlines.

- Qualify locked B host allocation across actual process/transport boundaries using a third, separately generated small monolithic oracle and 2/1/3 ownership. Preserve both earlier 2/2/2 profiles. Give B a separate same-basename source copy and remove it before A connects, requiring immutable complete-catalog startup counters and tracked native locks through inference. Keep full residency false for metadata/network/control/GPU gaps and retain all missing-middle/identity refusal cases.

- Expose quiescent per-stage invalidation through the experimental side header so a future coordinator can poison successful owners after another owner fails. Reuse the permanent failure guard, preserve ordinary contexts and require context recreation with retained weights. Keep running-work interruption, all-owner synchronization, epochs/transactions and replay as separate requirements.

- Separate semantic transaction state from connection frame sequences. Keep fixed-size owner metadata, exact running/applied/committed retries and one prior certificate; require complete A/B/C digest-chain receipts and an exact own applied receipt for local commit. Reject expired retries, bind fresh real contexts to strictly newer epoch/generation and reset all owners after uncertain outcomes. Authenticate and encode receipts, cache bounded replies and implement the global acknowledgement/publication barrier separately before production use.

- Encode transaction control with fixed versioned little-endian applied-receipt and complete-decision formats; reject reserved bytes and bind the full locally pending key. Authenticate frames before decoding. Use A-B/A-C control connections for rank-authenticated receipts and A-only decisions while retaining the A-B-C activation path. Add a distinct complete-certificate-bound commit acknowledgement before implementing publication.

- Give commit acknowledgements a distinct payload kind 3 and appended envelope kind 14, binding each actual local committed receipt to the entire canonical decision fingerprint. Keep one coordinator barrier per transaction with three-owner applied/committed masks; duplicates count once. Expose committed metadata only after all three ACKs, then require retained-payload verification before publication. Invalidate all owners on uncertainty; keep live dispatch, reply storage and real reset/replay separate integration work.

- Connect the ledger/barrier to actual graphs first in a fourth restricted synthetic process profile. Keep activation chaining and independently authenticated duplex control pairs, with separate directional keys/counters. Release diagnostic output only after A sends a distinct certificate-bound global-completion notice after all commit ACKs. Inject lost B ACK after local commit and require all actual owners to invalidate with zero output, then qualify fresh-process replay separately from retained-weight distributed recovery.

- Retain copied immutable unfragmented replies before applied acknowledgement, with one pending/one prior committed slot and shared byte/page/entry reservations lasting through final external leases. Bind local cache commit to the full certificate; do not re-execute expired or missing retries. Use explicit native-locked B reply payloads without fallback and keep metadata/network/full admission separate. Revoke future lease access on uncertainty after consumers stop. Use real kernel locks in sanitizer harnesses because intercepted mlock can silently be a no-op.

- Distinguish healthy reconnect after known global completion from uncertain transport failure. Reauthenticate fresh directional control codecs/counters, retain semantic owner/reply state, and repeat actual cached boundaries/certificates without graph execution or cursor movement. Keep uncertain failures on the all-owner reset path. Provide a canonical-byte boundary sender so retained unfragmented replies need no float alias or conversion.

- Qualify retained-weight recovery separately from process restart. Unwind every failed context/queue/reply owner before announcing reset readiness, require all-owner invalidation/zero output, and verify B returns to its model-only host baseline with no source file. Use a bounded test-controller plan for fresh session/newer epoch/topology, recreate contexts against the same models and compare full replay against the independent oracle. Keep production authenticated reset and prior client-history/RNG replay as separate work.

- Preserve committed response position separately from the recreated input/state cursor. Keep only a bounded fixed fingerprint journal for globally completed fixture output, replay actual graphs from zero and verify already released rows without appending them again. Append only new globally completed rows, with no inference readback from diagnostic disk files. Keep this recovery journal separate from prefix reuse, durable snapshots and production client/RNG history.

- Return a compact C-to-A terminal outcome after global commit, bound to the complete decision and exact pending step. Start with explicitly limited native stateless greedy mode and eight raw FP32 candidates; retain outcomes for idempotent retry and verify against independent full logits. Do not send normal full-vocabulary arrays over LAN or label raw logits as probabilities. Bind future sampling/seed configuration and transactional RNG separately before enabling it.

- Measure actual native stream transfers and owned CPU graph durations before performance tuning. Count partial completion, saturate rather than wrap, retain healthy reconnect totals and validate an independent protocol-byte ledger. Keep readiness wait distinct from physical link latency and report epoch/model-preload boundaries explicitly. Telemetry does not imply kernel-buffer residency, GPU timing or target throughput.

- Let authenticated A introduce each original request hash through fixed BEGIN, while B/C retain local control over every state coordinate and bound. Remove token plans from workers, hash actual intermediate input and preserve full-key duplicate refusal across reconnects. BEGIN agreement is distinct from resource admission, applied state and global commit; bind future complete sampling/request semantics before production use.
