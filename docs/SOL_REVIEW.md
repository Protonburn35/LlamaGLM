# Implementer review notes

These are self-review notes for the component checkpoints, not an independent review or final production-pipeline signoff. A constrained three-process CPU fixture exists; the production distributed runtime remains unimplemented.

Reviewed paths: GGUF callback reader, typed metadata access, plan/range arithmetic, tensor routing, state-size arithmetic, expert slab bounds, command-line/output behavior, metadata-only fetch and executable Windows workflows. Applied security, design, testing and general coding checks from the repository's code-review guidance where relevant to this fork.

Findings addressed:

- The GGUF total block count includes NextN; use 45 target layers plus one explicit draft block.
- The publisher uses INT32 KV-head arrays, while synthetic fixtures can use UINT32. Check the array element type and count before selecting the matching cast.
- Bound header bytes and fixed-header tensor/KV counts before the upstream reader allocates metadata containers. Refuse incomplete or duplicate shards/tensors and unknown global names. Do not claim tensor data or admission was verified.
- Check byte arithmetic before addition/multiplication. Expert file spans include all 288 slabs, enforce matrix orientation/shape and reject invalid expert IDs or overflowing offsets. Never change routing to fit a cache.
- Require dense/routed/shared FFN projections at all target/NextN layers. The later native schema checker below closes the metadata shape/count gap; payload integrity and runtime admission remain separate.
- Account for C's optional MTP dependency on A's token embedding table. MTP stays disabled.
- Windows internal architecture fixtures require static llama libraries. Keep the fixture; fix the build configuration rather than deleting checks.
- Windows workflow permissions are contents-read, third-party Actions are pinned, CUDA archives retain official SHA256 verification, CCCL has a specific commit, no weights or credentials enter artifacts, and hosted CPU tests are not called GPU validation.

Remaining review gates: real-quant/GPU qualification of the owned-layer graph/loader, strict laptop residency, expert lease lifetimes, production transport/control integration and transaction recovery, full API/prefix/snapshot state, and release dependencies/launchers. These require implementation and new focused tests before a broad candidate review is possible.

Owned-loader extension reviewed: the complete three-range plan is copied per model; only GLM5Next is admitted; unknown file tensors remain visible to strict loader accounting; unowned entries are removed before ordinary payload reads, with no whole-file mmap/prefetch. Generic optional tensor passes see null unowned layer pointers. Stable public parameter structs are unchanged; the C interface lives in an experimental side header. Byte comparisons and non-GLM regression exercise both modified and untouched paths.

Local evaluator extension reviewed: all three memory filters share weight ownership; B/C input and A/B output widths preserve every FP32 mHC stream; C alone collapses streams. Headless outputs bypass pooling/logit/sampling work and retain every row. Output-ID and memory inputs are built only when used, including pure-KDA/DSA splits. Ordinary monolithic context creation still rejects partial models. The stage factory/defaults and decode guards bound context, enforce FP16 sparse storage, causal seq-0 append-only positions and unsupported-feature refusal. An RAII guard permanently invalidates a context after uncertain preparation/compute, and a CPU abort fixture proves a memory clear cannot silently reuse it. Independent monolithic boundary captures and logits qualify both split layouts locally. Remaining gates include three-process transactions, exact Windows/CUDA numerical results, the real mixed quant, 1M allocations and physical residency; local fixture parity does not establish those.

Frame component review: no native struct serialization, unchecked peer-sized allocation or cryptographic primitive implementation. Dimensions/counts/positions are bounded before products and payload reads; full frame bytes are authenticated with native providers. Context identity, channel, nonces and direction separate link keys. Sequence advancement follows successful authentication; any receiver failure is permanent. Tests include independently encoded vectors and mutations, rather than only encoder-to-decoder roundtrips. Later extensions below add proof/socket paths. Canonical identity/limit negotiation, fragment execution/order and session/transaction semantics remain mandatory application integration work.

Mutual proof extension reviewed: fixed 160-byte envelopes use a separate authenticated domain, phase and actual sender/receiver roles. Both nonces, identity, channel, versions and reserved bytes are covered. Server/client freshness comes from native RNG, with no production test bypass. A replayed challenge still requires a fresh-client-bound final server proof; stale client/final proofs refuse across new connections. Agreed bindings are gated on completion, failures cannot be retried on the same object, and handshake secret copies clear after completion/failure. Independent challenge and every-byte tampering tests exercise the new path. The TCP extension below adds lifecycle/deadlines; canonical identity construction and application READY remain unimplemented.

TCP extension reviewed: fixed numeric interfaces and bounded backlog/buffer requests; no DNS/wildcard listener or remote command/path interface. Socket ownership precedes fallible configuration, including accepted handles. Nonblocking exact I/O and proof/frame drivers retain absolute deadlines, normalize peer closure, suppress POSIX SIGPIPE, and permanently stop failed streams. Atomic interruption keeps handle lifetime separate from I/O cancellation; users must join before destruction/move. Frame size inspection precedes body allocation and authentication precedes return. Actual loopback tests exercise partial transfers, backpressure, independent control, malformed peers, deadlines and interruption. Windows behavior still awaits the exact new source run. These are components, not a reviewed three-rank model/session service; topology, quotas, canonical identities, secret provisioning and all-owner transaction recovery remain open.

Three-process extension reviewed: the oracle executes separately before the workers and writes independent references; no A/B/C worker constructs a full model. Each uses the owned-loader/evaluator API, and B/C consume actual authenticated four-stream inputs. The harness checks distinct PIDs, exact owned ranges, aggregate payload coverage, all output lengths, finite numerical values and byte-exact boundaries. Missing-middle refusal checks the authentication failure and absence of any model output. Workers reject non-fixture geometry before payload loading, bind only loopback, require a configured temporary 32-byte key file and accept no remote file/command requests. The parent joins/terminates only its own children and removes synthetic data/key files. The fixture has fixed chunks/session coordinates and no production control/transaction semantics; it cannot establish real-model identity, hardware residency, GPU or full-context correctness.

Native-schema extension reviewed: descriptor-only mode is guarded by no allocation, no file/provider source, no mmap and lazy OFF. Actual descriptors populate the normal required/optional shape checks and unknown-tensor count, rather than the virtual provider synthesis path. Geometry limits guard native assertions. Declared NextN tensors are checked without creating a draft context. All returned weight buffers must be zero-sized with null data, and no model handle escapes. Real 1,412-tensor metadata plus nine malformed cases pass on Linux/MSVC; payload bytes and hardware admission remain unverified.

Identity extension reviewed: system SHA256, bounded explicit fields and length-prefixed identifiers, complete three-stage coverage, canonical shard ordering and Windows case-alias/path rejection. Exact header hashes cover tokenizer/template and quant descriptors without a full-weight checksum requirement. Source revision is configuration provenance, not binary attestation. Independent canonical golden and per-field mutations pass native CNG, and three actual processes refuse changed tokenizer metadata. Production provisioning and admission are still absent.

Whole-chunk bridge reviewed: forward ranks only, locally expected complete semantic coordinates, one bounded float input, one bounded frame, exact fragment ordering and bit-preserving little-endian IEEE representation. No partial input escapes to the model; allocation/MAC/order/EOF/deadline failures discard it and permanently interrupt the stream. One deadline includes copying. The model fixture uses this bridge across 64 KiB fragment boundaries and remains byte-exact. A full 128 MiB CPU transfer, malformed tails, budgets and failure cleanup pass native Windows. This does not supply distributed commit, cancellation/reconciliation, peer quotas or production memory admission. All three extensions are Windows-qualified through f11238d49; a broad production-candidate review remains premature.
